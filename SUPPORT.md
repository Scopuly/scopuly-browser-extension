# Support

For setup questions, dApp integration problems and reproducible non-sensitive
bugs, open a GitHub issue using the appropriate template.

For general Scopuly support, contact [info@scopuly.com](mailto:info@scopuly.com).

Do not include seed phrases, secret keys, signing keys, pairing links, relay
tokens, full request payloads or other private wallet data in an issue.
Security vulnerabilities must follow [SECURITY.md](SECURITY.md).
