# Support

Extension setup and troubleshooting guidance is available at
[https://extension.scopuly.com/support/](https://extension.scopuly.com/support/).

For dApp integration problems and reproducible non-sensitive bugs, open a
[GitHub issue](https://github.com/Scopuly/scopuly-browser-extension/issues)
using the appropriate template.

For general Scopuly support, contact
[info@scopuly.com](mailto:info@scopuly.com).

Do not include seed phrases, secret keys, signing keys, pairing links, relay
tokens, full request payloads or other private wallet data in an issue or
support message. Security vulnerabilities must follow
[SECURITY.md](SECURITY.md).
