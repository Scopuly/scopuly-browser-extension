# Changelog

## 0.3.4 - 2026-08-17

- Added recognition and presentation of Scopuly signing devices on macOS.
- Added pairing-link guidance for Scopuly for Mac while retaining QR pairing on
  iOS and Android.
- Updated the public product name to `Scopuly – Stellar Signer` and removed
  mobile-only wording from the extension, store copy and reviewer assets.
- Added `macos` to the public Bridge protocol schema and validation coverage.
- Kept the provider contract at `0.3.0`, with no new browser permissions,
  remote code or Bridge server requirements.

## 0.3.3 - 2026-08-14

- Published the cross-browser source and release baseline used for the next
  browser-store update.

## 0.3.2 - 2026-08-11

- First store release for Chromium, followed by Firefox and Microsoft Edge.
